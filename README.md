# Animasi Logo ZaSha.Online

Demo layar pembuka (splash screen) dan tampilan masuk dengan animasi logo, dibuat dengan HTML, CSS, dan JavaScript biasa tanpa server dan tanpa build. Tidak ada pengiriman data; formulirnya hanya tampilan.

Berkas: `index.html` dan `logo.jpg`. Font dimuat dari Google Fonts.

Demo: https://editorzash.github.io/demo_animasi_logo/
